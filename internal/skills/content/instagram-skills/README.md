# instagram-skills (vendored)

Selected skills from https://github.com/sergebulaev/instagram-skills, copied unchanged
(MIT License, Copyright (c) 2026 Sergey Bulaev; see LICENSE). The upstream commit is in
UPSTREAM_COMMIT.

Only the writing skills and the references they cite are bundled. Skills that need
external tools (ig-audience-insights, Apify/Publora clients, Python scripts) are left out;
the app tells the model to skip any publishing or tool step in the bundled ones.
To update, copy the same paths again from a newer upstream checkout.
